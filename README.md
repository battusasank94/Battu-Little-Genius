# Battu Little Genius V2
- Seven worlds: Dream House, Brain Master, Smart Learning, Creative World, Little Chef, Animal World and Story Garden.
- English, Telugu and Hindi interface labels.
- Expanded room decoration, 8-pair memory, four quiz categories, drawing with PNG export, four-step fruit recipe, animal names and three short stories.
- CSS animated mascot, responsive phone/tablet design, local progress counters and a simple parent progress area.
- No ads, analytics, accounts, external APIs, paid assets or subscriptions.

## Update GitHub Pages
Replace the existing five repository files with these V2 files at the repository root, commit to `main`, and keep Pages configured to `main` / root. Open the site online and refresh to install the V2 service worker.

## Notes
Visuals are emoji and CSS-based 3D-style effects, not a full 3D engine. Speech depends on voices installed on the device. The parent area is not PIN-secured and does not enforce screen-time limits. Test on the target devices before wider distribution.
